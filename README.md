# Стройка — iPhone PWA MVP

Это мобильное веб-приложение для управления строительством дома.

Возможности:
- главная с прогрессом;
- работы и статусы;
- график;
- расходы;
- журнал;
- добавление фото через iPhone;
- данные сохраняются локально в браузере.

Для публикации нужен любой статический хостинг (например, Vercel/Netlify/GitHub Pages). После публикации на iPhone: Поделиться → На экран «Домой».
